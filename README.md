This collection provides documentation for 344 security tools found in Kali Linux. It serves people who want to understand network security, penetration testing, and ethical hacking techniques. Each tool includes a tutorial, list of commands, and an explanation of how it relates to common attack stages.

## 🎯 Purpose of this project

Modern security work relies on a vast array of software. Learning these tools takes time. This resource organizes information according to the MITRE ATT&CK framework. This structure helps you understand how tools fit into real-world security assessments. Whether you prepare for an OSCP exam, participate in CTF events, or work in professional security, these guides provide the information you need to operate safely and effectively.

## 📖 Using the documentation

The documentation follows a standard format for each tool. Understanding this format allows you to find answers quickly.

- **Objective:** The goal of the tool and why security professionals use it. 
- **Setup:** Necessary configurations before you run the software.
- **Commands:** A list of useful commands with descriptions for each flag.
- **Scenario:** A practical example showing the tool in use during a simulated attack.
- **Defense:** Tips on how to detect or prevent this type of activity on a network.

## 🛡️ Educational framework

The materials map directly to the MITRE ATT&CK framework. This framework breaks down the lifecycle of a security event. You can look at the folders to see how tools group logically.

- **Reconnaissance:** Tools meant to gather information about a target.
- **Initial Access:** Ways to find entry points into a system.
- **Execution:** Methods for running code on a target machine.
- **Persistence:** Techniques used to maintain long-term access.
- **Privilege Escalation:** How users gain higher levels of control.
- **Exfiltration:** Ways to move data out of a network.

## 💡 Learning path suggestions

If you are new to this field, start with the tools labeled for reconnaissance. These tools create the foundation for all other security work. Once you grasp how to gather information, move toward tools used for vulnerability scanning and network discovery. Always practice these skills in a controlled lab environment. Do not test these tools on any network or system without explicit permission from the owner.

## 🛠️ Frequently asked questions

**Do I need a Linux computer to use these tools?**
While the tools belong to the Kali Linux distribution, the documentation provides command references that you can study on Windows. Some users prefer to run a Linux virtual machine to follow the tutorials hands-on.

**Are these tools malicious?**
The tools themselves act as utilities. They help test security defenses. Intent determines whether their use is malicious. Use this resource to build your knowledge and improve your defensive capabilities.

**How often do you add new tutorials?**
The database updates when new tools become common in the security community. Check the repository periodically for updates to the tutorials.

**Can I contribute to the project?**
Contributions are welcome. If you find a mistake in a command or want to add a new scenario, open a pull request. Clear explanations help everyone in the community.

## 🏁 Finalizing your setup

Ensure your security software, such as Windows Defender, does not flag the tools as threats. Security tools look for vulnerabilities, which often triggers these programs. If they block your practice, add an exclusion for the folder where you keep these tools.
